# Awesome Shells

A curated list of **desktop shells** for **Linux Wayland compositors**.  
This repository compiles projects that provide cohesive user-interface layers—panels, launchers, notifications, wallpapers, indicators, and other desktop-shell components—on top of modern Wayland compositors.

> **Contributions welcome!**  
> Feel free to submit PRs for missing shells, screenshots, updates, or new comparison categories.

## 🧭 What Counts as a “Shell”?

This repository includes projects that offer at least one of the following:

- Desktop panels or taskbars  
- Application menus / launchers  
- Wallpaper or background control  
- Notifications and system indicators  
- Lock screen / login UI  
- Integrated window-management UI  
- Cohesive desktop “environment” elements

Lightweight components (e.g., standalone bars) are only included when part of a broader shell experience.
